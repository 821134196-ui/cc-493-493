# 消防通道临停管控系统

物业记录消防通道上临停车辆的一体化系统：**发现上报 → 接单巡查 → 联系劝离 → 升级拖移（负责人审批）→ 驶离/拖离 → 另一名保安清障复核 → 结案留痕**。

零第三方依赖：Python 3.10+ 标准库（`http.server` + `sqlite3`）+ 原生前端，SQLite 存事件，本地目录存照片，短信网关与车牌识别（LPR）为**可控模拟**。

## 一条命令启动

```bash
./run.sh            # 默认 http://127.0.0.1:8000，可带端口：./run.sh 8080
# 或
python3 server.py
```

## 页面

- **通道平面图**：SVG 总平图，以绿色「出」字**消防出入口为视觉锚点**；**红色仅给正在阻断的通道**（闪烁路面 + 阻/急图钉），待复核为琥珀色，历史/已结案事件一律中性灰。点通道=保安快捷上报/住户查看本人通知；点图钉进事件详情。
- **事件卡片/列表**：车牌、占用区域、发现时间、现场照片、占用时长（实时跳动）、**实际处置人**；重复上报显示「已合并 ×N」。
- **事件详情**：完整**时间线**、**联系记录**（短信/电话/现场 + 结果 + 模拟网关状态）、照片墙、按当前状态出现的处置按钮。
- **清障复核页**：仅列待复核事件；实际处置人会看到「不能自行复核」提示，须换另一名保安。
- **统计页**：指标卡 + 各楼栋堆叠条形（灰=已结案 / 蓝=在案非阻断 / 红=正在阻断）+ 明细表。
- **模拟控制台**：切换短信失败/正常、注入下一次 LPR 识别结果、查看短信发件箱。
- **手机端**：「拍照上报」红色脉冲按钮醒目；照片入口 `capture="environment"` 直接调起后置摄像头，底部弹层适配小屏。

## 核心业务规则

1. **不反复开单**：`events(plate_norm, channel_id)` 上有部分唯一索引（`WHERE status<>'closed'`），同一车辆同一通道在案期间重复上报只累加 `merged_report_count` 并写 `repeat_report` 时间线，不生成新单；并发下由 `BEGIN IMMEDIATE` + 唯一约束兜底。
2. **二次驶入**：待复核期间车辆二次驶入 → 原事件重开（`reentry` 留痕，清除待复核数据）；结案后再驶入才开新单。
3. **异员复核**：驶离/拖离由处置人登记 → 进入 `pending_review`；复核接口强制 `reviewer != handler`，同员返回 403；复核不通过则事件重开。
4. **并发结案**：复核结案为条件更新 `WHERE status='pending_review'`，`rowcount==0` 即 409，8 线程并发恰 1 成功。
5. **升级拖移**：保安只能申请，`tow-approve` 强制 supervisor 角色 + 前端二次确认；可驳回、可**取消拖移**（自动或手动均写 `tow_cancelled`）。
6. **封闭不可改**：closed 事件的一切写动作返回 409；住户全站只读，跨楼栋/非本人车辆 403。
7. **留痕场景**：联系失败（contact_logs + sms_outbox 双记录）、车牌识别错误（`plate_corrected` 存旧牌→新牌）、二次驶入（`reentry`）、紧急救援占道（`kind=emergency`，上报时或处置中均可标记）、拖移取消（`tow_cancelled`）。
8. **照片**：存 `data/uploads/`（见下），访问按事件可见关系鉴权，不接受裸文件路径。

## 文件结构

```
server.py            # 路由 + 全部事件生命周期动作 + 权限
database.py          # SQLite schema / 种子 / 车牌归一化 / 时长
static/index.html    # 单页外壳（登录、5 个页签、上报/详情抽屉、确认弹窗）
static/styles.css    # 视觉纪律：红=阻断、绿=消防出入口、历史=中性灰
static/app.js        # 平面图渲染、卡片、时间线、拍照、统计、模拟控制台
tests/test_system.py # 20 个端到端用例（线程内起真实 HTTP 服务）
run.sh               # 一条命令启动
data/                # 运行时生成：firelane.db + uploads/
```

## 数据存放与重置

- 默认在项目下 `data/`（SQLite + 上传照片）。可用环境变量 `FIRELANE_DATA=/your/dir ./run.sh` 改变位置。
- 全新演示：停止服务后删除 `data/` 目录再启动即可（账号/通道会自动重建种子）。
